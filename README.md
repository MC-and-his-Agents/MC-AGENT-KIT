# MC-SKILLS

Source and distribution repository for Agent Skills and Agent Plugins developed by MC. Each artifact declares its real compatibility instead of assuming one universal agent harness.

[中文版](./README.zh-CN.md)

## Standalone Skills

Standalone skills live directly under `skills/<skill>/` or in a themed collection at `skills/<collection>/<skill>/`. Collections are navigation only: every skill remains independently installable.

List available skills:

```bash
npx skills add MC-and-his-Agents/MC-SKILLS --list
```

Install one skill:

```bash
npx skills add MC-and-his-Agents/MC-SKILLS --skill write-a-goal
```

Install all standalone skills for one supported agent:

```bash
npx skills add MC-and-his-Agents/MC-SKILLS --skill '*' --agent codex
```

Use `--agent claude-code` for Claude Code. See the collection pages for theme-specific batch commands:

- [`dev`](./skills/dev/README.md) — software development and engineering decisions.
- [`design`](./skills/design/README.md) — product, interaction and interface design.

Each standalone skill owns an independent SemVer in its `SKILL.md` `metadata.version`. During `0.x`, compatible fixes increment patch; new capabilities and explicitly documented breaking changes increment minor. From `1.0.0`, versions follow standard major/minor/patch semantics. Collections have no version.

## Agent Plugins

Plugin-contained skills stay inside their plugin and are distributed only through that plugin. They are not standalone entries in the `npx skills` catalog.

### Codex

```bash
codex plugin marketplace add MC-and-his-Agents/MC-SKILLS --ref main
codex plugin add codegraph-intelligence@mcskills
codex plugin list
```

### Claude Code

```bash
claude plugin marketplace add MC-and-his-Agents/MC-SKILLS
claude plugin install codegraph-intelligence@mcskills
claude plugin list
```

Other harnesses are supported only when the artifact explicitly declares and verifies an installation path.

## Maintenance

Regenerate the directory tables after changing skill or plugin metadata:

```bash
python3 scripts/render-plugin-directory.py
```
