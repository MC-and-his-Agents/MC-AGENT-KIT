# Image Art Direction

把图像请求当作一次完整的视觉制作，而不是关键词堆叠。先设计一张具体画面，再把它编译成图像模型容易执行的自然语言规格。

## 确定交付意图

根据请求选择实际需要的工作，不把每次请求都扩张成完整制作流程：

- **只写提示词**：交付可直接使用的最终提示词。
- **生成图像**：整理必要规格后生成并交付图像。
- **编辑或重制**：先检查目标图像，建立锁定项与可编辑项，只改变用户允许修改的内容。
- **评审或解释**：区分可见内容、视觉判断和改进建议；不擅自生成新图。
- **定向修订**：只修正用户指出或检视发现的实质偏差，并保留已经成功的特征。

普通审美选择可以结合用途合理推断。只有缺失信息会实质改变主题、身份、硬约束或交付形式时才询问用户。

## 提取约束

在内部区分约束，不要求向用户展示标签：

- **硬约束（Hard constraints）**：身份、主体数量、几何与结构、文字与品牌、指定画幅、关键位置关系，以及用户明确要求保持的参考内容或时代边界。
- **软偏好（Soft preferences）**：情绪、色彩倾向、背景丰富度、一般光线风格、颗粒强弱和装饰性细节。

参考图任务同时建立：

- **锁定项（Locked）**：用户要求保留的身份、几何、数量、比例、位置、姿态、结构、文字、Logo 和其他可见特征。
- **可编辑项（Editable）**：用户允许修改的环境、光线、天气、材质、色彩、背景或构图范围。

只重新设计 Editable；不把“高级化”“写实化”或“提升品质”解释为重新设计主体。用户参考中的 Locked 优先于自动补全；Logo、包装文字和精密产品结构默认不重新设计。

约束看似冲突时，先区分目标与实现手段，并寻找不改变主要意图的唯一合理解。只有存在多个同等合理方案，且选择会实质改变主题、身份、硬约束或交付结果时才询问用户。

## 视觉设计

只构建会影响当前画面的部分，不把这些维度强制输出成表格：

1. **创意意图（Creative Intent）**：确定用途、受众、主要视觉意图和情绪。
2. **成像媒介（Imaging Mode / Medium）**：先确定这张图假定由什么生产方式产生，例如手机抓拍、杂志写真、电影剧照、商业产品摄影、Catalog / Cutout 产品摄影或建筑可视化；后续镜头、光线、材料与成像痕迹服从这个媒介。
3. **美术指导（Art Direction / Mise-en-scène）**：让主体、造型、道具、环境和色彩属于同一个视觉世界。
4. **动作与场面调度（Blocking / Interaction）**：确定主体的位置、朝向、视线、动作、手部、接触关系以及动作造成的可见结果。明显动作优先来自剧情、职业活动、产品操作或人物关系；没有动作需求时，让手部和身体处于自然、低复杂度状态。
5. **镜头设计（Camera / Shot Design）**：按需要展示的信息选择景别、机位、距离、构图、焦点和画幅。
6. **合理光源（Motivated Lighting）**：说明关键光线的来源、方向、颜色、软硬，以及它如何作用于主体和材质。
7. **视觉层级（Visual Hierarchy / Gestalt）**：区分主视觉、支撑信息和环境语境；除非叙事需要多中心构图，不让背景拥有与主体相同的视觉权重。
8. **材质定义（Material Definition）**：用具体材料及其透明度、粗糙度、反射和形变替代空泛的质量形容词。
9. **物理与摄影可信度（Physical / Photographic Plausibility）**：让结构、受力、表面、景深、运动、曝光和成像痕迹符合选定媒介。
10. **因果一致性（Causal Coherence）**：让动作、姿态、环境状态、光照、材质变化、运动和成像痕迹具有可解释的原因。优先写产生视觉结果的原因，不孤立堆叠反射、烟雾、边缘光或动态模糊。

## 按需读取专业参考

读取能够解决当前决策缺口的最小 reference 集合。不要仅因主体名称命中而机械加载多个文件；主 skill 足以完成时不读取额外 reference。

- 剧情瞬间、blocking、摄影机、可见性、视觉层级或因果组织较复杂：读取 [visual-language.md](references/visual-language.md)。
- 黑色物体、金属、玻璃、液体、织物、皮肤、食物或混合光源是关键：读取 [lighting-materials.md](references/lighting-materials.md)。
- 成像媒介不明确，或需要把“手机抓拍”“电影剧照”“商业广告”等转成具体视觉规律：读取 [imaging-modes.md](references/imaging-modes.md)。
- 多主体、精确数量、属性或空间绑定、遮挡、重复结构、文字、Logo 或编辑漂移风险较高：读取 [t2i-behavior.md](references/t2i-behavior.md)。
- 用户要求解释理论依据：读取 [methodology.md](references/methodology.md)。普通生图任务不读取它。

## Prompt 编译

把已完成的画面设计翻译成模型容易执行的指令：

1. **实体 → 属性 → 关系**：把属性紧邻所属实体；明确数量、相互位置、接触和遮挡。方向容易混淆时使用 `image-left`、`image-right` 等观众视角，并保持一致。
2. **可见性（Visibility）**：检查关键规格在当前裁切、朝向、遮挡、景深和光线下是否可见；必要时调整姿态、切面或摄影机，而不是要求不可见区域承担信息。
3. **决策闭合（Decision Closure）**：最终提示词不保留无意义的“A 或 B”；多个方案都成立时，选定最符合主要意图的一个。
4. **信息预算（Information Budget）**：只保留会改变身份、构图、动作、材料、光线、尺度或语境的约束。每个画面区域的承载能力有限；主体较小时，不让面部微细节、小型首饰、微小纹样或不可见结构相互竞争。
5. **交互复杂度（Interaction Complexity）**：每个握持、穿戴、遮挡、交叉、人物接触或物体嵌套都增加关系漂移风险；只保留具有视觉或叙事价值的交互。
6. **失败感知约束（Failure-aware Constraints）**：先用正向规格定义正确结果，再针对当前画面的高风险结构、文字、数量、手部、参考保真或媒介误判添加少数约束；不复制通用负面词库。

使用具体名词、动作、材料和空间关系；`masterpiece`、`stunning`、`8K` 等标签不能代替可观察的视觉规格。只写有作用且彼此一致的镜头、光线与媒介参数。

## 按主体补全

原始需求缺少领域规格且主 skill 不足以合理补全时，读取 [subject-playbooks.md](references/subject-playbooks.md) 中当前主体对应的部分；不要扩展到无关领域。

## Execution Gate

在最终生成或交付提示词前内部检查，不默认展示：

1. 用户的硬约束和 Locked 是否全部进入最终规格，且未被后续设计覆盖；
2. 主体数量是否明确；
3. 属性是否绑定到正确实体；
4. Blocking、手部和接触关系是否成立；
5. 关键视觉信息是否能从当前摄影机、景别和朝向看到；
6. Primary 是否明确，支撑信息和背景是否意外争夺视觉权重；
7. 光线、材料和成像痕迹是否存在合理因果关系；
8. 是否仍有未闭合的无意义 A/B 决策；
9. 是否加入了过多没有视觉价值或超出局部承载能力的信息；
10. 当前构图最容易失败的关系是否已被控制。

任一项不成立时先修正规格；只有无法在现有硬约束内解决时才请求用户决定。

## 输出

默认交付连贯的自然语言视觉规格；用户要求结构化、教学或解释时再展示拆解。只写提示词时直接交付最终 Prompt；生成或编辑图像时以同一规格执行。

## 结果检视与定向修订

仅在当前任务实际生成或编辑图像、且结果可见时使用：

- **Critical**：身份、数量、产品或建筑结构、Locked、核心动作等硬约束错误；必须修正。
- **Major**：摄影机、Blocking、接触、视觉中心或光线因果明显偏离，实质削弱主要意图；通常修正。
- **Minor**：不影响识别、叙事和硬约束的轻微背景、色温或装饰差异；通常保留。

修订指令同时写明“修正什么”和“保持什么”，只处理 Critical 与确实影响目标的 Major，不为 Minor 偏差重新生成整个画面。默认最多进行一次自主定向修订；仍有实质偏差时交付当前最佳结果并说明。

## 边界

- 不把任何示例中的性别、族裔、年龄、体型、性感化、品牌、武器、画幅或摄影媒介变成默认值。
- 产品和食物请求按单张商业摄影处理，不扩展为平台规范、商品图集、投放、点击率或转化率工作流。
