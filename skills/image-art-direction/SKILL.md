# Image Art Direction

把图像请求当作一次视觉制作，而不是关键词堆叠。将用户意图转成模型可执行的文字视觉预演（textual previsualization），同时保留用户对产物、风格和修改范围的选择权。

## 先确定交付意图

根据请求选择实际需要的工作，不把每次请求都扩张成完整制作流程：

- **只写提示词**：交付可直接使用的最终提示词。
- **生成图像**：整理必要规格后生成并交付图像。
- **编辑或重制**：先检查目标图像，建立锁定项与可编辑项，只改变用户允许修改的内容。
- **评审或解释**：区分画面中的可见内容、视觉判断和改进建议；不擅自生成新图。

普通审美选择可以结合用途合理推断。只有缺失信息会实质改变主题、身份、硬约束或交付形式时才询问用户。

## 建立约束优先级

在内部区分约束，不要求向用户展示标签：

- **硬约束（Hard constraints）**：身份、主体数量、几何与结构、文字与品牌、指定画幅、关键位置关系，以及用户明确要求保持的参考内容或时代边界。
- **软偏好（Soft preferences）**：情绪、色彩倾向、背景丰富度、一般光线风格、颗粒强弱和装饰性细节。

发生冲突时优先满足硬约束；两个硬约束无法同时成立时，指出冲突并请求用户决定，不用软偏好掩盖失败。

## 视觉决策模型

只构建会影响当前画面的部分，不把这些维度强制输出成表格：

1. **创意简报（Creative Brief）**：确定用途、受众、媒介、情绪和必须保持的约束。
2. **成像媒介（Imaging Mode / Medium）**：先确定这张图假定由什么生产方式产生，例如手机抓拍、杂志写真、电影剧照、商业棚拍、电商主图或建筑可视化；后续镜头、光线、材料与成像痕迹服从这个媒介。
3. **美术指导与场面调度（Art Direction / Mise-en-scène）**：让主体、造型、道具、环境、色彩和空间关系属于同一个视觉世界。
4. **镜头设计与视觉预演（Shot Design / Previsualization）**：选择有明确目的的景别、机位、距离、构图、焦点和画幅；确认关键规格在当前裁切、遮挡和朝向下实际可见，必要时通过姿态、开口、切面或摄影机位置使其进入画面。
5. **合理光源（Motivated Lighting）**：说明关键光线的来源、方向、颜色、软硬，以及它如何作用于主体和材质。
6. **视觉层级与图形—背景（Visual Hierarchy / Gestalt）**：在复杂场景中区分主视觉、支撑信息和环境语境；除非叙事需要多中心构图，不让背景拥有与主体相同的对比度、清晰度、尺寸或色彩权重。
7. **材质定义（Material Definition）**：用具体材料及其透明度、粗糙度、反射和形变替代空泛的质量形容词。
8. **组合与属性绑定（Compositionality / Attribute Binding）**：用清楚的“实体 → 属性 → 关系”表达颜色、服装、道具和位置归属。
9. **物理与媒介可信度（Physical / Medium Plausibility）**：加入与选定媒介一致的皮肤、表面、景深、运动、曝光或成像痕迹。
10. **因果与行为一致性（Causal / Behavioral Coherence）**：让动作、姿态、环境、光线、材料变化和成像痕迹具有可解释的原因。不要孤立添加雨水、烟雾、运动模糊、边缘光或戏剧姿势。
11. **失败感知提示（Failure-aware Prompting）**：根据主体数量、手部交互、文字、重复结构、透明或反射材质、复杂空间和参考图编辑等当前特征，预测少数最可能影响结果的失败模式。

## 按需读取专业参考

不要默认加载所有 reference。当前任务出现对应决策时才读取：

- 剧情瞬间、blocking、摄影机、可见性、视觉层级或因果组织较复杂：读取 [visual-language.md](references/visual-language.md)。
- 黑色物体、金属、玻璃、液体、织物、皮肤、食物或混合光源是关键：读取 [lighting-materials.md](references/lighting-materials.md)。
- 成像媒介不明确，或需要把“手机抓拍”“电影剧照”“商业广告”等转成具体视觉规律：读取 [imaging-modes.md](references/imaging-modes.md)。
- 人像、Cosplay、产品、食物、建筑、电影场景或历史复原需要领域化补全：读取 [subject-playbooks.md](references/subject-playbooks.md)。
- 多主体、精确数量、属性或空间绑定、遮挡、重复结构、文字、Logo 或编辑漂移风险较高：读取 [t2i-behavior.md](references/t2i-behavior.md)。
- 用户要求解释理论依据：读取 [methodology.md](references/methodology.md)。普通生图任务不读取它。

## 编写视觉规格

- 先写画面是什么以及发生什么，再补充观众从哪里看、为什么能看到和哪些细节证明它可信。
- 把属性紧邻其所属实体；多主体场景明确相互位置。方向容易混淆时使用 `image-left`、`image-right` 等观众视角，并保持前后一致。
- 最终提示词消除无意义的备选分支。如果多个方案都满足用户意图，根据硬约束和整体视觉一致性选定一个，不写成“A 或 B”；只有用户明确需要随机变化时才保留并列选择。
- 让构图、色彩、环境和光线共同服务一个主要意图。背景负责提供支撑或语境，不自动增加无关细节。
- 只写有视觉作用的镜头参数。不要为了显得专业而同时堆叠相互冲突的焦段、景深、拍摄距离或成像媒介。
- 让光线能够在场景中找到来源，并描述材料如何响应光线；不要用 `cinematic lighting` 代替实际光照设计。
- 使用具体名词、动作、材料和空间关系。`masterpiece`、`stunning`、`8K` 等标签不能代替可观察的质量规格。
- 摄影瑕疵必须与媒介一致。不要为了“真实”机械加入噪点、压缩、运动模糊或不对称。
- 控制信息预算：优先保留能改变身份、构图、动作、材料、光线、尺度和语境的约束；删除后不会明显改变预期画面的句子通常不进入最终提示词。
- 负面约束与实际风险成比例。先用正向规格定义正确结果，再针对高风险结构、文字、数量、手部、参考保真或媒介误判补充约束；不复制无关的通用负面词库。

提示词默认写成连贯的自然语言视觉规格。除非用户要求拆解、教学或结构化交付，不展示内部检查表或逐层解释。

## 按主体调整重点

- **人物或角色**：优先身份与识别特征、动作和手部关系、造型材料、环境线索及人物与背景的分离。
- **产品或食物**：优先几何形态、表面材质、摆放关系、尺度、反射和需要保留的商业信息。
- **建筑或室内**：优先空间功能、尺度、结构、材料、观察点、时间和天气。
- **电影或历史场景**：优先剧情瞬间、blocking、时代环境、材料与器物以及摄影机叙事。

这些是重点切换，不是固定模板。复杂任务读取 `subject-playbooks.md`；不要把人物摄影中的脸型、妆容或身体描述迁移到不相关领域。

## 参考图编辑：Locked / Editable

先建立两组视觉特征：

- **锁定项（Locked）**：用户要求保留的身份、几何、数量、比例、位置、姿态、结构、文字、Logo 和其他参考内容。
- **可编辑项（Editable）**：用户明确允许修改的环境、光线、天气、材质、色彩、背景或构图范围。

只重新设计 Editable；不把“高级化”“写实化”或“提升品质”解释为重新设计主体。用户参考中列为 Locked 的可见特征优先于自动补全；Logo、包装文字和精密产品结构默认不重新设计，除非用户明确允许修改。

## 生成前可执行性 Gate

在最终生成或交付提示词前快速检查：

1. 主成像媒介是否唯一，其他视觉选择是否与它一致；
2. 主体和数量是否唯一明确；
3. 关键属性是否绑定到正确实体；
4. 动作、接触关系及其结果是否物理成立；
5. 所有重要细节是否能在当前构图中看到；
6. 光线、材料变化和成像痕迹是否有合理来源；
7. 是否仍存在尚未解决的“A 或 B”视觉决策。

任一项不成立时先修正规格；只有无法在现有硬约束内解决时才请求用户决定。

## 边界

- 不把任何示例中的性别、族裔、年龄、体型、性感化、品牌、武器、画幅或摄影媒介变成默认值。
