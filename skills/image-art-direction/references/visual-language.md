# 视觉语言与镜头组织

## 何时读取

用于剧情瞬间、多人 blocking、复杂构图、镜头选择、主体分离、可见性或因果关系需要进一步设计的任务。

## 从叙事瞬间开始

先确定一个能被单帧观察的瞬间：

- 谁正在做什么；
- 这个动作刚发生、正在发生还是即将发生；
- 哪个可见结果证明了它；
- 观众第一眼必须理解什么。

“紧张”“高级”“电影感”不是动作。把它们转成姿态、距离、视线、接触关系、空间阻隔或环境变化。

## Blocking

- 给每个主体一个明确位置、朝向、动作和与其他对象的关系。
- 接触关系要描述双方：手如何握住道具，道具哪部分被遮挡，重量如何影响手腕或身体。
- 多人画面先确定角色功能，再决定人数；无叙事作用的人群只作为环境语境。
- 动作的结果应可见：行走可以带动衣摆，雨水会改变表面，热源可以产生蒸汽，重量会改变材料受力。

## 摄影机是信息选择器

按需要展示的信息选择景别，而不是从默认焦段开始：

- 远景适合空间、尺度和群体关系，不承担微观服装或表面细节。
- 中景适合动作、道具和环境关系。
- 近景适合表情、接触点或材料细节，但会牺牲整体空间。

检查摄影机高度、角度、主体朝向和遮挡。被裁切、背向镜头、藏在封闭物内部或处于强逆光暗面的信息，不应同时承担主要视觉任务。

## 视觉层级

在内部给元素分级：

1. **Primary**：第一眼必须识别的主体或动作。
2. **Supporting**：解释主体身份、动作或产品价值的信息。
3. **Context**：交代地点、尺度、时代或氛围的背景线索。

通过清晰度、对比度、尺寸、位置、颜色和负空间分配权重。背景不是越详细越真实；它只需要提供足够语境。

## 因果一致性

用“原因 → 表面或动作响应 → 成像结果”检查视觉效果：

- 雨和车辆灯 → 湿路面反射 → 夜景中的方向性高光；
- LED 屏 → 冷色环境光 → 临近表面出现相应反射；
- 沸腾汤底 → 蒸汽 → 局部遮挡与高光扩散；
- 山坡地形 → 分层结构与挡土 → 建筑尺度和受力可信。

无法指出来源的效果通常应删除或重新设计。

## Decision Closure

最终规格必须像导演已经做完决定。把“入口或二层连廊”“短裤或裙子”“展会或摄影棚”收敛为一个最符合意图的方案。仅当用户明确要求随机变化时才保留分支。

## 校准示例

低信息量：

> luxury black watch, cinematic lighting, masterpiece, 8K, dramatic

更可执行：

> 黑色机械腕表以三分之四角度置于石墨灰台座上，狭长侧光形成可控反射，分别勾勒拉丝表面和抛光倒角；背景低对比，视觉中心只落在表盘与表壳结构。

差别不在长度，而在主体、观察点、光源、材料响应和视觉层级已经闭合。
