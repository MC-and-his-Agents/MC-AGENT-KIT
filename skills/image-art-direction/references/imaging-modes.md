# 成像媒介与生产方式

## 何时读取

当用户只给出“真实”“电影感”“杂志感”等模糊表述，或多个成像方式可能冲突时读取。

## 选择规则

成像媒介不是装饰风格，而是一份生产合同。每个最终 prompt 选择一个主媒介；其他特征只能作为辅助，不能同时要求互相矛盾的成像规律。

| 主媒介 | 核心控制 | 合理痕迹 | 避免 |
|---|---|---|---|
| 手机抓拍 | 近距离、自然机位、环境光、即时动作 | 轻微压缩、局部曝光不均、少量运动柔化 | 棚拍级完美反射、无来源轮廓光、胶片扫描特征 |
| 自然街拍 | 人物与真实街道互动、环境语境、抓拍节奏 | 行人或衣摆轻微运动、自然景深 | 正面证件照姿势、过度清空背景 |
| 杂志编辑写真 | 明确的人物身份、姿态、造型和背景关系 | 受控但不过度洁净的皮肤与服装细节 | 电商抠图、模板化成功人士道具 |
| 电影剧照 | 单一剧情瞬间、blocking、production design、motivated lighting | 与选定拍摄介质一致的颗粒、运动和高光响应 | 只有“cinematic”标签、无剧情的海报姿势 |
| 商业产品摄影 | 几何、边缘、反射、接触关系和视觉中心 | 高光形状可控、背景干净、局部高解析 | 随机运动模糊、夸张景深、结构漂移 |
| 电商主图 | 产品保真、均匀光线、清晰轮廓、规范占比 | 轻微接触阴影 | 重做 Logo、增加配件、戏剧化背景 |
| 美食摄影 | 结构、表面、温度线索、摆盘与用餐语境 | 蒸汽、凝结、碎屑或融化仅在物理合理时出现 | 不可见内部、塑料高光、无限重复食材 |
| 建筑摄影或可视化 | 几何、尺度、结构、材料、流线和观察点 | 合理天空反射、人物尺度参照 | 夸张超广角、无支撑结构、窗户漂移 |
| 历史复原图 | 时代环境、建筑、材料、器物、人物活动和观察点 | 与时代和场景一致的构造、磨损与生活痕迹 | 现代材料、时代符号混杂、影视城式过度装饰 |

## 从用途反推媒介

- “像路人拍到”通常收敛为手机抓拍，而不是商业人像。
- “菜单图”通常收敛为受控美食摄影，而不是餐桌纪实。
- “高端腕表广告”通常收敛为商业产品摄影，而不是电影剧照。
- “空间尺度和自然采光”通常收敛为建筑摄影或建筑可视化。

选择媒介后，把不属于它的噪点、焦段、光线和后期术语删除。成像痕迹应由媒介产生，而不是单独作为“真实感”装饰。
